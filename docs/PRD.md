# Product Requirements Document (PRD)
## FindIt – Campus Lost and Found System

### 1. Product Overview
FindIt is a campus web application that helps students and staff report lost items, publish found items, and connect with people who can return them. The application uses campus accounts and administrator moderation to improve trust.

### 2. Problem Statement
Lost-item notices are scattered across social media, notice boards, and informal groups. Campus members need one searchable system to report, find, and reclaim belongings.

### 3. Goals
- Provide one place to submit lost and found item reports.
- Make item reports searchable by category, location, and date.
- Help owners contact finders while protecting sensitive information.
- Allow administrators to moderate reports and resolve disputes.

### 4. Target Users
- **Student/Staff (User):** Create and manage their own reports; search listings; submit claims.
- **Administrator:** Review reports and claims, remove inappropriate posts, and manage item status.

### 5. MVP Features
1. User registration and login.
2. Create a lost or found report with title, description, category, location, date, and optional image link.
3. Browse, search, and filter reports.
4. View report details.
5. Submit a claim/request for a found item with identifying details that are not public.
6. Users can edit or close their own reports.
7. Admin can review flagged reports and claims and mark items resolved.

### 6. User Stories
- As a student, I want to post a lost item so other campus members can help me find it.
- As a finder, I want to post an item without exposing its identifying details.
- As an owner, I want to search by location and category.
- As an admin, I want to review suspicious reports to reduce false claims.

### 7. Success Criteria
- Registered users can create and find reports.
- Users cannot change another user's reports.
- Only admins can access admin-only functions.
- Claims are not shown publicly.
- Item records can be marked resolved.

### 8. Scope Exclusions for MVP
No mobile app, AI item matching, payments, or live chat.
