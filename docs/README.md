# FindIt Documentation

FindIt is a campus lost-and-found system designed to help students and staff report and locate lost or found items.

## Project Documents

- [Product Requirements Document (PRD)](PRD.md) — Product goals, users, features, and scope.
- [Software Requirements Specification (SRS)](SRS.md) — Functional and non-functional requirements.
- [Technical Design Document (TDD)](TDD.md) — System architecture, API design, data model, and technical implementation.

## Release Plan

- **MVP:** Core lost-and-found reporting and CRUD REST APIs, running locally.
- **Beta:** Authentication, role-based access control (RBAC), user profile dashboard, security permissions, and deployment.
